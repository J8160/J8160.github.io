This is placeholder text showing how a piece about music will look.

To embed a recording, go to the video on YouTube, choose **Share**, then **Embed**, and paste the code on its own line between two paragraphs.

To add your own recording or a picture of a score, upload the file to the `assets` folder and link to it:

```
<audio controls src="/assets/my-recording.mp3"></audio>

![Bars 1–8 of the first movement](/assets/score-excerpt.png)
```

If your site's address ends in a folder name, such as `/writing-site/`, put that folder name before `/assets` in those links.
